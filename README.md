# AULA-1-VETOR-   dia 19/10/2026
VETOR LING C
1) Desenvolva um algoritmo em linguagem de programação C, que leia 8 número inteiros
que o usuário informar. Armazene-os em um Vetor. Ao final Imprima os valores retirando de
dentro do vetor.

2) Desenvolva um algoritmo em linguagem de programação C, que pergunte a quantidade
de valores a serem calculados. Leia os valores do tipo Inteiro com comando FOR. Após crie
outra estrutura com comando FOR para ler os dados do já inseridos no vetor e realizar a
soma de todos os valores. Imprima o resultado final da somatória.

3) Desenvolva um algoritmo em linguagem de programação C, que pergunte a quantidade
de valores a serem calculados. Leia os valores do tipo Float com comando FOR. Após crie
outra estrutura com comando FOR para ler os dados do já inseridos no vetor e realizar a
Média de todos os valores. Imprima o resultado final da Média.

4) Desenvolva um algoritmo em linguagem de programação C, que pergunte a quantidade
de valores a serem calculados. Leia os valores do tipo Inteiro com comando FOR. Após crie
outra estrutura com comando FOR para ler os dados e encontrar qual é o Menor e o Maior
valor inserido no vetor.

5) Desenvolva um algoritmo em linguagem de programação C, que pergunte a quantidade
de valores a serem calculados. Leia os valores do tipo Inteiro com comando FOR. Após crie
outra estrutura com comando FOR para ler os dados e imprimir os valores na ordem inversa
a que for inseridos dentro do vetor.

6) Desenvolva um algoritmo em linguagem de programação C, que pergunte a quantidade
de valores a serem calculados. Leia os valores do tipo Inteiro com comando FOR.Crie mais
2 vetores, sendo um vetor denominado “int par[x]” e o outro “int impar[x]” com o mesmo
tamanho do primeiro vetor informado pelo usuário. Após crie outra estrutura com comando
FOR para ler os dados a ser inseridos pelo usuário. Em uma nova estrutura FOR, percorra
todos os dados do vetor principal, verificando se o valor inserido é Par ou Impar, assim
como inserindo o valor em seu vetor correspondente. Ao final, imprima o Vetor Par e o Vetor
Impar.

7) Desenvolva um algoritmo em linguagem de programação C, que crie um vetor principal
de tamanho 5 do tipo inteiro. Insira valores inteiros no vetor principal. Crie um vetor auxiliar
de tamanho 8. Através de uma estrutura FOR, copie os valores inseridos a principio do
vetor principal para o vetor auxiliar. Insira mais 3 valores inteiros no valor auxiliar, nos
espaços que que ficaram vazio. Imprima os 8 valores do vetor auxiliar.

8) Desenvolva um algoritmo em linguagem de programação C, que utilizando as bibliotecas
“stdlib.h” e “time.h”, crie um vetor de inteiro de tamanho 100, utilize o comando “RAN()” para
preencher os valores automaticamente com valores no intervalo entre 50 a 100. Ao final,
imprima os valores do vetor.

9) Desenvolva um algoritmo em linguagem de programação C, que utilizando as bibliotecas
“stdlib.h” e “time.h”, crie um vetor de inteiro de tamanho 10000, utilize o comando “RAN()”
para preencher os valores automaticamente com valores no intervalo entre -880 a 1500.
Crie outro mecanismo FOR e conte quantos valores são Negativo e quantos são Positivos.
Ao final, imprima a quantidade de valores Negativos e Positivos.

10) Desenvolva um algoritmo em linguagem de programação C, que utilizando as
bibliotecas “stdlib.h” e “time.h”. Pergunte ao usuário qual o nome do Jogo da Loteria
Esportiva ele deseja jogar. Quantos números devem ser sorteados de forma aleatória. Qual
o valor inicial e final deste jogo.
